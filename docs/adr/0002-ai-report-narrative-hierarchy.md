# Keep one AI-owned report narrative hierarchy

The default `$where-tokens-went` and `report` HTML use three distinct AI-owned narrative levels: an Evidence-backed Audit Overview gives the first impression of overall activity and usage shape, report Findings expose important patterns the user may not notice, and Key Session Analysis explains where a pattern occurs and how to act. Deterministic code owns facts, checks, rankings, and unavailable states; it does not generate competing judgments such as “stable,” “main cost,” or “main driver.” The independent Overview is deliberately not a project-progress summary because the sanitized Audit cannot prove completed project outcomes, and the Session ranking table omits a driver column because Turn candidates are not causal conclusions.
