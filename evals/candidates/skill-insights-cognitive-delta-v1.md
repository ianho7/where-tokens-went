# Candidate Prompt Delta: evidence-first Cognitive Delta selection

This file is an experiment candidate, not the authoritative Prompt. Read the current authoritative `prompts/skill-insights.md` first and apply this delta only for the candidate lane.

Use the immutable Skill Snapshot as the only source of claims. Choose at most three distinct Ahas in this order when the evidence exists:

1. Capability Aha: when a high-use Skill has verified content on both sides, make the title say what is locally non-replaceable. If the unique excerpt is a Harness, local-fact, hard-constraint, or tool rule and the other excerpt is a generic response or analysis procedure, state the contrast explicitly: the evidence currently supports a local Harness contract as the distinctive value, while the generic response scaffold is not by itself a Capability Delta. Do not broaden this to Run or evidence binding unless those excerpts are present in this Snapshot.
2. System-topology Aha: if a family metric shows a naming family dominates the call graph, prefer the concentration contrast over a generic long-tail restatement. Call it a naming family or usage family. Do not call it one capability unless content evidence from at least two members supports that stronger claim.
3. Usage-boundary Aha: prefer a counterintuitive usage contrast only when the Snapshot exposes both sides. Associated or traceable Tokens are not caused by a Skill, and overlapping associations are not additive. If per-Skill Token evidence is absent from the Snapshot, do not manufacture a frequency-versus-scale Aha; preserve the unknown or omit it.

Treat a calls-per-task outlier without Trigger Trace as an investigation candidate, not a final Mechanism Aha. Name the Skill if mentioning it. Do not infer early/middle/late trigger behavior from repeated calls alone.

Every selected Aha must create a different cognitive and decision delta. Prefer a sharper claim over a broader claim: show the evidence that changes the maintenance decision, then state only the supported uncertainty. Keep all quantitative values in deterministic evidence references for the renderer; do not copy numbers into prose.
